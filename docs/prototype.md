# Прототип интерфейса

## Назначение

Этот документ фиксирует прототип веб-сайта «Конфигуратор рабочего места программиста» для требования о разработке макета в Figma/Adobe XD/Sketch. Реализация проекта соответствует описанным ниже экранам, визуальной системе и пользовательским сценариям.

## Концепция

Визуальная идея проекта — технический премиальный конфигуратор в стиле рабочей станции. Интерфейс использует темный фон, янтарные акценты, крупную типографику, SVG-иконки и плотные функциональные блоки.

Основной референс дизайн-системы находится в `stitch_setup_summary_page/anthracite_mono/DESIGN.md`.

## Цветовая система

| Роль | Цвет | Использование |
| --- | --- | --- |
| Основной фон | `#0d0d0d` | общий фон страниц |
| Поверхность | `#181818`, `#202020` | карточки, панели, блоки |
| Основной текст | `#efebe4` | заголовки и важная информация |
| Вторичный текст | `#b8ada0` | описания, подписи, пояснения |
| Акцент | `#ffc060` | кнопки, активные элементы, цены |
| Мягкий акцент | `#ffddb4` | hover-состояния, иконки, бейджи |
| Дополнительный акцент | `#66d7ff`, `#8e55d8` | технические и декоративные маркеры |

## Типографика

| Роль | Шрифт | Применение |
| --- | --- | --- |
| Заголовки | Georgia / Times New Roman | крупные заголовки и названия блоков |
| Интерфейс | Inter / системный sans-serif | навигация, карточки, кнопки, описания |
| Технические подписи | SFMono / Consolas / monospace | цены, статусы, счетчики, метки |

## Экран 1: Главная страница

Файл реализации: `index.html`.

### Структура

1. Верхняя навигация:
   - логотип MONOSPACE;
   - ссылки «Главная», «Каталог», «Моя сборка», «О нас»;
   - CTA «Собрать ПК».
2. Hero-блок:
   - фоновое изображение рабочего места;
   - заголовок «Соберите свое идеальное рабочее место»;
   - кнопки «Начать сборку» и «Смотреть каталог».
3. Блок преимуществ:
   - карточка производительности;
   - карточки «Топовое железо» и «Кастомный дизайн».
4. Блок «Почему Monospace?»:
   - качество;
   - поддержка;
   - совместимость.
5. Каталог:
   - карточки категорий из XML;
   - переход в конфигуратор.
6. Производительность:
   - метрики и прогресс-бары.
7. Сборки сообщества:
   - визуальные примеры рабочих мест.
8. Отзывы и FAQ.
9. Футер:
   - описание бренда;
   - ссылки;
   - форма рассылки.

### Адаптивность

- на десктопе используется широкая композиция с несколькими колонками;
- на планшетах сетки перестраиваются в две колонки;
- на мобильных экранах контент становится одноколоночным;
- нижняя мобильная навигация ведет в конфигуратор.

## Экран 2: Конфигуратор

Файл реализации: `configurator.html`, React-ядро: `src/react/App.jsx`.

### Структура

1. Верхняя навигация:
   - повторяет стиль главной страницы;
   - активный пункт «Моя сборка».
2. Вводный блок:
   - заголовок «Конфигуратор рабочего места»;
   - краткое описание XML-каталога и проверки совместимости.
3. React-область:
   - боковая панель категорий;
   - список товаров активной категории;
   - сводка сборки.

### Состояния интерфейса

| Состояние | Описание |
| --- | --- |
| Загрузка | показывается статус загрузки XML |
| Данные загружены | отображаются категории, товары и сводка |
| Товар выбран | карточка получает активное состояние, цена пересчитывается |
| Есть проблема совместимости | выводится предупреждение в сводке |
| Сборка очищена | выбранные товары удаляются из `localStorage` |

## Пользовательский сценарий

1. Пользователь открывает `index.html`.
2. Изучает преимущества и категории.
3. Нажимает «Начать сборку» или карточку категории.
4. Переходит на `configurator.html`.
5. Выбирает компоненты в категориях.
6. Следит за итоговой стоимостью.
7. Проверяет предупреждения совместимости.
8. При необходимости очищает сборку и начинает заново.

## Соответствие реализации прототипу

| Элемент прототипа | Реализация |
| --- | --- |
| Главный экран | `index.html`, секция `.hero` |
| Каталог компонентов | XML + `src/js/main.js` |
| Интерактивная сборка | `configurator.html` + React |
| SVG-иконки | `iconPaths` в `src/js/main.js` |
| Темная дизайн-система | `css/main.css`, переменные `:root` |
| Адаптивность | media queries в `css/main.css` |
| Проверка совместимости | `src/react/utils/compatibility.js` |

## Контрольные размеры

| Экран | Размер | Ожидаемое поведение |
| --- | --- | --- |
| Mobile | 360×740 | одна колонка, компактная навигация, без горизонтальной прокрутки |
| Tablet | 768×1024 | двухколоночные блоки, конфигуратор в одну колонку |
| Desktop | 1366×768 | полноценные сетки, боковая панель конфигуратора |

## Итог

Прототип описывает две основные страницы проекта и служит текстовой спецификацией макета. Он связан с фактической реализацией и может быть использован как основа для переноса в Figma, Adobe XD или Sketch.
