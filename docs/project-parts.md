# Части разработки

Этот файл дублирует логику Excel-трекера в текстовом виде, чтобы архитектура проекта была понятна прямо в репозитории.

## Выполнено

- Часть 0: Подготовка гибридной архитектуры.
- Часть 1: Страница `configurator.html`.
- Часть 2: React/Vite только для конфигуратора.

## Следующая часть

Запрос для Codex:

```text
Реализуй часть 3: свяжи текущий лендинг с configurator.html.
```

Ожидаемый результат:

- кнопка `Собрать ПК` ведет на `configurator.html`;
- кнопка `Начать сборку` ведет на `configurator.html`;
- пункт `Моя сборка` ведет на `configurator.html`;
- текущие якорные переходы главной страницы не ломаются.

## Основное правило

Главная страница `index.html` остается статичной. React используется только для ядра конфигуратора.
