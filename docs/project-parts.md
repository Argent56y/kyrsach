# Части разработки

Этот файл дублирует логику Excel-трекера в текстовом виде, чтобы архитектура проекта была понятна прямо в репозитории.

## Выполнено

- Часть 0: Подготовка гибридной архитектуры.
- Часть 1: Страница `configurator.html`.
- Часть 2: React/Vite только для конфигуратора.
- Часть 3: Навигация с лендинга.
- Часть 4: Расширение XML.
- Часть 5: Парсер XML для React.
- Часть 6: Интерфейс конфигуратора.
- Часть 7: Выбор компонентов, цена и совместимость.
- Часть 8: Финальная проверка и полировка.
- Часть 9: Проверка качества и подготовка к GitHub.

## Текущий статус

Часть 9 выполнена: добавлен локальный `npm run check`, настроен GitHub Actions workflow с Super-Linter, подготовлена инструкция `docs/testing.md`.

## Основное правило

Главная страница `index.html` остается статичной. React используется только для ядра конфигуратора.
