# Гибридная архитектура MONOSPACE

## Решение

Проект остается гибридным:

- главная страница и промо-блоки остаются на чистом HTML/CSS/JS;
- ядро конфигуратора будет реализовано на React;
- React будет подключаться только на отдельной странице `configurator.html`;
- общий визуальный стиль остается в `css/main.css`;
- данные для лендинга и конфигуратора остаются в XML.

Такой подход сохраняет уже готовый дизайн и одновременно добавляет полноценное интерактивное ядро для курсового проекта.

## Текущие файлы, которые сохраняем

| Файл | Назначение |
| --- | --- |
| `index.html` | Главная HTML5-страница сайта |
| `css/main.css` | Основная CSS3-дизайн-система проекта |
| `src/js/main.js` | DOM-логика главной страницы: SVG-иконки, XML-категории, FAQ, слайдер |
| `src/data/configurator.xml` | XML-источник данных |
| `src/scss/` | Минимальный SCSS-слой для требований курсового проекта |
| `stitch_setup_summary_page/` | Референсы дизайна |

## Файлы, которые появятся в следующих частях

| Файл или папка | Назначение |
| --- | --- |
| `configurator.html` | Отдельная страница React-конфигуратора |
| `src/react/main.jsx` | Точка входа React-приложения |
| `src/react/App.jsx` | Корневой компонент конфигуратора |
| `src/react/components/` | React-компоненты интерфейса |
| `src/react/hooks/` | Хуки для XML, сборки и совместимости |
| `src/react/utils/` | Парсер XML, расчет цены, проверка совместимости |
| `css/configurator.css` | Дополнительные стили только для React-конфигуратора, если общего CSS будет мало |

## Связь страниц

После создания `configurator.html` кнопки на главной странице будут вести туда:

- `Собрать ПК`;
- `Начать сборку`;
- `Моя сборка`.

Главная страница не будет зависеть от React. Если React-сборка временно сломается, лендинг все равно останется доступным.

## Источник данных

Основной источник данных: `src/data/configurator.xml`.

В следующих частях XML будет расширен под полноценные категории:

- процессор;
- видеокарта;
- оперативная память;
- накопитель;
- монитор;
- клавиатура;
- мышь;
- кресло;
- стол;
- аудио;
- освещение.

React будет загружать XML через `fetch`, парсить его через `DOMParser` и хранить выбранные компоненты в состоянии приложения.

## Порядок реализации

1. Создать `configurator.html`.
2. Настроить React/Vite только для конфигуратора.
3. Связать кнопки главной страницы с конфигуратором.
4. Расширить XML.
5. Написать парсер XML.
6. Собрать интерфейс конфигуратора.
7. Добавить выбор компонентов, расчет цены, совместимость и сохранение.

## Ограничения

- Не переносить `index.html` в React.
- Не подключать сторонние UI-библиотеки.
- Не ломать текущий `css/main.css`.
- Сохранять визуальное направление из `stitch_setup_summary_page`.
- Новые React-стили писать в обычном CSS.
