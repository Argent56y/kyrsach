# Пояснение к проекту

## Тема

Веб-сайт «Конфигуратор рабочего места программиста».

Проект помогает подобрать компоненты рабочего места: компьютерные комплектующие, монитор, периферию, мебель и дополнительные аксессуары. Пользователь может открыть главную страницу, перейти в конфигуратор, выбрать товары из XML-каталога, увидеть итоговую стоимость и базовую проверку совместимости.

## Цель проекта

Цель курсового проекта — разработать адаптивный веб-сайт с несколькими страницами, XML-данными, SCSS/CSS-оформлением и JavaScript-логикой. Для интерактивного ядра используется React, но главная страница остается независимой статичной HTML-страницей.

## Структура сайта

| Файл | Назначение |
| --- | --- |
| `index.html` | Главная страница сайта с промо-блоками, каталогом, FAQ и навигацией |
| `configurator.html` | Отдельная страница React-конфигуратора |
| `css/main.css` | Основные стили проекта |
| `src/scss/` | SCSS-слой для требований курсового проекта |
| `src/js/main.js` | DOM-логика главной страницы: SVG-иконки, XML-каталог, FAQ, слайдер, форма |
| `src/data/configurator.xml` | XML-каталог категорий и товаров |
| `src/react/` | React-ядро конфигуратора |
| `docs/` | Пояснения, архитектура, тестирование и план частей |

## Архитектура

Проект использует гибридный подход:

- главная страница работает на HTML5, CSS3 и обычном JavaScript;
- React подключается только на странице `configurator.html`;
- данные для каталога и конфигуратора хранятся в XML;
- Vite используется для разработки и production-сборки.

Такое разделение сохраняет независимость лендинга: если React-часть временно недоступна, главная страница продолжает открываться.

## XML-данные

Файл `src/data/configurator.xml` содержит:

- метаданные каталога;
- категории компонентов;
- обязательность разделов;
- стартовую цену категории;
- изображение категории;
- список товаров;
- характеристики товаров для отображения и проверки совместимости.

В текущей версии каталога: 13 категорий и 36 товаров.

## JavaScript на главной странице

Файл `src/js/main.js` выполняет несколько задач:

- заменяет текстовые маркеры иконок на inline SVG;
- загружает категории из XML и выводит карточки каталога;
- включает FAQ-аккордеон;
- управляет горизонтальным каталогом на широких экранах;
- обрабатывает форму рассылки без перезагрузки страницы.

## React-конфигуратор

React-часть находится в `src/react/`.

Основные элементы:

- `useXmlData.js` загружает и парсит XML;
- `xmlParser.js` превращает XML в объекты JavaScript;
- `useBuild.js` хранит выбранные товары и сохраняет их в `localStorage`;
- `price.js` считает итоговую стоимость;
- `compatibility.js` проверяет обязательные разделы, сокет CPU/платы и запас блока питания;
- `App.jsx` собирает интерфейс категорий, карточек товаров и итоговой сборки.

## Адаптивность

Интерфейс адаптирован под мобильные, планшетные и десктопные экраны:

- верхняя навигация упрощается на малых экранах;
- каталог на мобильных экранах становится вертикальным списком;
- конфигуратор перестраивается из многоколоночного вида в одну колонку;
- широкие карточки и текстовые блоки защищены от горизонтального переполнения.

## Соответствие требованиям

| Требование | Реализация |
| --- | --- |
| HTML5 и XML | `index.html`, `configurator.html`, `src/data/configurator.xml` |
| CSS3 и SCSS | `css/main.css`, `src/scss/` |
| Несколько веб-страниц | `index.html`, `configurator.html` |
| SVG-графика | inline SVG-иконки создаются в `src/js/main.js` |
| JavaScript DOM | FAQ, каталог, форма и слайдер на главной странице |
| Адаптивность | media queries в `css/main.css` |
| Тестирование | `npm run check`, Vite build, GitHub Super-Linter |
| GitHub-подготовка | `README.md`, `docs/testing.md`, `.github/workflows/super-linter.yml` |

## Проверка

Основная локальная команда:

```bash
npm run check
```

Она проверяет структуру проекта, XML-каталог, отсутствие черновых маркеров, независимость главной страницы от React и production-сборку Vite.

## Публикация на GitHub

Для публикации нужно загрузить репозиторий на GitHub. После push во вкладке Actions должен запуститься workflow `Super-Linter`. Подробная инструкция по проверке находится в `docs/testing.md`.
